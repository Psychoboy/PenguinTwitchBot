### General & Branding Settings

#### Application Title
Customizes the branding displayed in browser window titles across all dashboard views. Useful if you run multiple bots or customize the dashboard name for your channel.

#### Default Weather Location
The default city name or postal code (e.g. `85234`, `London`, `Austin, TX`) returned when a viewer uses `!weather` without passing a location argument.

#### Star Citizen Referral URL
Configures the referral link placed in the bottom navigation bar's Support section. Leave default to support the bot developer, or replace with your own referral URL.
