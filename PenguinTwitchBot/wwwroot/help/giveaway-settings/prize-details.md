# Giveaway Prize Configuration

In [Giveaway Settings](/giveaway/settings), streamers configure the current giveaway prize, promotional media, and terms shown to viewers.

## Current Giveaway Details

- **Prize**: The title/name of the item being raffled (e.g. "Mechanical Gaming Keyboard", "$50 Steam Gift Card", "Custom Emote Commission").
- **Image URL**: Direct image link to the prize artwork or photo. Displayed prominently in the public giveaway page and OBS alerts.
- **Prize Tier**: Optional tier classification (e.g. Tier 1, Grand Prize, Consolation).
- **Additional Details**: A rich markdown editor supporting formatted terms, eligibility restrictions, shipping limitations, and alert callouts. Rendered directly on the viewer entry portal.
- **Reset Giveaway**: Clears all current giveaway entries, reset drawing history, and resets prize status for a clean slate.
