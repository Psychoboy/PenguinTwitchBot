### OpenAI (AI Features) Setup

Powers intelligent, dynamic shoutouts for raided or incoming streamers and contextual chat interactions.

#### Obtaining an OpenAI API Key
1. Log in to the [OpenAI API Keys Dashboard](https://platform.openai.com/api-keys).
2. Click **+ Create new secret key** and enter an identifier (e.g. `PenguinTwitchBot`).
3. Copy your secret key immediately (it is only displayed once).
4. Paste the key into the OpenAI tab, enable the toggle, and click **Test Connection**.

> [!WARNING]
> **Usage Caps & Spend Alerts:**
> OpenAI API usage is billed by token consumption. We recommend setting a monthly spending limit and budget notifications in your OpenAI Billing preferences to avoid unexpected usage costs.
