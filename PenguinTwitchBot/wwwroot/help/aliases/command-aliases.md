# Command Aliases

The [Aliases](/commands/aliases) manager allows streamers to create shorthand synonyms or convenient nicknames that redirect to any existing command in the bot.

## Why Use Aliases?

- **Shorthand Shortcuts**: Create 1 or 2 letter shortcuts for frequently typed commands (e.g. `!p` -> `!points`, `!so` -> `!shoutout`, `!sr` -> `!song`).
- **Typo Tolerances**: Map common viewer typos or misspellings (e.g. `!point`, `!tickets`, `!gamblee`) to the correct primary command.
- **Multiple Triggers**: Provide multiple intuitive names for the same feature (e.g. `!battle` and `!arena` mapping to `!ffa`).

## Creating an Alias

1. Enter the new **Alias Trigger** (e.g. `p`).
2. Enter the existing **Target Command** (e.g. `points`).
3. Click **Add Alias**.
4. The alias immediately executes the target command with all original arguments forwarded seamlessly.
