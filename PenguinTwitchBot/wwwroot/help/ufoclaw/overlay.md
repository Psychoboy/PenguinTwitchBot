# UFO Claw Overlay

Add **UFO Claw** in the Overlay Editor. Its default size is **1920x1080** with a transparent background; the widget settings include Fit Full Screen and a link to management. Save the layout, then use the existing compositor browser-source URL in OBS. For a standalone source, use `/ufo.html?key=<overlay-key>` with the shared overlay security key. Without that key the overlay cannot acknowledge the finished animation, so the result action will not be dispatched.

The source starts hidden and requires an explicit Show from the bot page or UFO Claw Control sub-action, including after a service restart. Hide completes any pending grab immediately. An unacknowledged grab is superseded when a new grab starts. The source has no operator toolbar, preview background or prize-selection buttons. It fills the available browser-source resolution while preserving round prize shapes. In Appearance & Sound or the widget settings, turn off **Show prize pit background** to remove the backing and rail while keeping the balls. Set independent left and right safe gaps to keep the pit, claw, and result panel clear of cameras; values use 1920x1080 design pixels and scale with the source. Prize objects remain large and may overlap in crowded pits; the selected object lifts clear for the result. Ball colors vary deterministically around each configured base color.

The default grab duration is 20 seconds. Suspense timing is derived from each claw travel distance at a fixed movement speed, with short fixed pauses for catching and dropping; longer trips take proportionally longer rather than being compressed into fixed per-feint slots. Suspense drops are enabled at a 20% chance and can be switched off or adjusted from 0 to 100%; configure a maximum of zero to five false catches. A sequence may drop no balls, and the winning ball may be part of a multi-ball feint. Labels stay visible, so any pickup could be the winner until the final re-catch and reveal. The animation is seeded from the grab ID, so reconnects replay the same feint and cannot change the server-selected winner.

The overlay bootstraps from `/api/overlay/ufoclaw-state` and subscribes to the `ufoclaw` WebSocket topic. A reconnect restores the same grab and winner, without repeating old sounds or result actions. After the claw locks and retracts the winner to the UFO, the browser sends an acknowledgement using the overlay security key; the server dispatches the already-selected result immediately. The winner label and reveal cue appear at that same point. There is no timeout fallback: use Hide to complete a grab without an overlay, or start another grab to supersede one that never acknowledged. Auto-hide runs after the configured reveal hold; otherwise the winner stays visible until another operation.

Original arcade motor, grab, drop, lift, catch, and reveal WAVs are bundled under `wwwroot/media/ufo_claw_*.wav` and play by default. The browser synth is a fallback if an asset cannot play; optional grab/reveal files replace the matching defaults. Mute/volume and missing images do not affect selection. OBS/browser autoplay restrictions may require allowing audio. Reduced-motion preference disables the suspense movement. A disconnected status indicator is diagnostic, not a failed prize draw.
