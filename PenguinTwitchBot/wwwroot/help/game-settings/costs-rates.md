# Game Costs, Odds & Multipliers

Each game can be fine-tuned to balance your channel's virtual economy, ensuring rewards remain exciting while preventing point inflation.

## Common Game Parameters

Inside each game's configuration panel in **Game Settings**:

- **Point Type Selector**: Choose which currency (from **Point Settings**) is used for bets, entry fees, and payouts.
- **Minimum & Maximum Bets**:
  - Sets bounds on how few or how many points a chatter may risk in a single command.
  - Helps protect newer chatters and limits massive runaway point spikes from high rollers.
- **Win Chance / Percentage**:
  - The probability (0% to 100%) that an entry or attempt succeeds.
  - For group games like **Heist**, base win percentages scale dynamically based on the total number of participants joining the crew.
- **Payout Multipliers**:
  - Controls reward returns upon winning (e.g. 1.5x, 2x, 5x).
  - Slots features distinct multipliers for partial matches (2 matching symbols) versus jackpot triples (3 matching symbols).
- **Cooldowns**:
  - Global cooldown between successive rounds of the game to avoid chat clutter.
  - Per-user cooldowns to prevent individual viewers from monopolizing the game.
- **Entry Window Duration**:
  - For multiplayer games like Heist and FFA, defines the countdown in seconds during which other viewers can enter their bets before the round resolves.
