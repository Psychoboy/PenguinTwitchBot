# Chat Games Overview

PenguinTwitchBot includes a suite of interactive chat minigames that engage viewers and allow them to wager, win, or cooperate using channel points.

## Available Games & Default Commands

| Game | Default Command | Description |
| :--- | :--- | :--- |
| **Defuse** | `!defuse <color>` | Choose a wire and try to defuse the bomb. |
| **Heist** | `!heist <amount>` | Join a team heist and try to escape with the loot. |
| **Gamble** | `!gamble <amount>` | Wager points on a roll and build toward the jackpot. |
| **Slots** | `!slot <amount>` | Spin the slots for a point payout. |
| **Roulette** | `!roulette <amount>` | Risk points in a high-stakes roulette game. |
| **FFA** | `!ffa` | Join a free-for-all and try to be the last viewer standing. |
| **Duel** | `!duel <viewer> <amount>` | Challenge another viewer to a point wager; use `!accept` or `!deny` to respond. |
| **Dice Roll** | `!roll` or `!dice` | Roll two dice for a chance to win points. |
| **Steal** | `!steal <viewer>` | Attempt to steal points from another viewer. |
| **First** | `!first` | Claim a stream reward based on how early you join. |

## Accessing Game Settings

Open the [Games hub](/games), choose a chat game, and use its **Settings** tab to select its point type and configure any available gameplay settings. The **Automation** tab links supported outcome events to regular actions and triggers. Command aliases and cooldowns link to their entries in Default Commands.

## Related Point Settings

- **Add Active** and **Mod Spam** are under **Point Settings > Point Activities**.
- **Bonus Tickets** and **Twitch Event Bonus** are under **Loyalty Bonuses**.
