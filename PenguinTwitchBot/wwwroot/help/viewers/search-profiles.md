# Community Viewers & Profiles

The **Community Viewers** view (`/community/viewers`) provides moderators and streamers with quick access to viewer records, engagement history, and profile diagnostics.

## Finding Viewers

Use the **Find Viewer** search box at the top of the page:
- Enter at least 3 characters of a Twitch username.
- Click **Search** or press Enter.
- The results table shows all matching viewers with their Twitch profile avatar, username, and system ID.

## Viewer Profile Information

Selecting or inspecting a viewer profile provides key metadata:
- **Twitch Identity**: Twitch User ID and current username.
- **Activity Timestamps**: First seen in chat and last seen activity timestamps.
- **Engagement Metrics**: Total message count and watch time accumulated across streams.
- **Currency Balances**: Balances across all configured point types (e.g. Points, Giveaway Tickets).
- **Moderation Status**: Whether the user is currently banned or timed out in channel chat.
