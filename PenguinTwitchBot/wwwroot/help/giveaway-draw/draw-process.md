# Drawing Giveaway Winners

The [Draw Giveaway](/giveaway/draw) view is the live control center during broadcast giveaways.

## Lifecycle Controls

- **Open / Re-open Giveaway**: Opens ticket submissions, allowing viewers to run `!enter`.
- **Close Giveaway**: Stops new entries immediately when the entry deadline is reached.
- **Draw Winner**: Initiates a randomized, ticket-weighted drawing among all eligible participants.
- **Reset Giveaway**: Erases current entries and winner queue to prepare for a fresh raffle.

## Default Commands for Drawing

Streamers and authorized moderators can also execute drawings directly from Twitch chat:
- `!open`: Opens the giveaway for entries.
- `!close`: Closes the giveaway.
- `!draw`: Draws the next winner.
- `!resetdraw`: Resets the active drawing state.
