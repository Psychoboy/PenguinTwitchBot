🐧 Penguin Twitch Bot — Extension Settings

Configure your self-hosted bot connection, features, and tab ordering for your channel's panel extension.

🔌 Bot Server Connection
The public HTTPS address of your self-hosted PenguinTwitchBot instance. Leave blank if testing on the same host.
🎛️ Enabled Tabs

Select which tabs should appear in the Twitch panel for viewers. Note: Tabs are also hidden if disabled in your bot's core settings.
